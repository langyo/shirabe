# shirabe

**أتمتة المتصفح بتصميم جديد — التحكم بمتصفحات عائلة Chromium (headless) عبر CDP، مع محلّل خلفية تلقائي على غرار ort.**

shirabe مكتبة خفيفة بلغة Rust لأتمتة المتصفح وخادم تنقيح. تُقود أي متصفح يتحدث Chrome
DevTools Protocol — Google Chrome وChromium وMicrosoft Edge — عبر محرّك CDP واحد مكتوب
يدويًا، وتكشف كل ذلك عبر واجهة HTTP صغيرة. وهي العمود الفقري للمتصفح المستخرج من
مُغلِّف tairitsu والمُعزَّز ليعمل وحده.

الفلسفة هي نفسها فلسفة [ort](https://crates.io/crates/ort) مع ONNX Runtime:
**لا ينبغي أن تضطر لتثبيت متصفح يدويًا.** تُجلب نسبيّة مثبّتة من Chrome for Testing إلى
ذاكرة تخزين مؤقت مشتركة (عند البناء أو عند أول استخدام)، وتُحدَّد وتُقاد بشفافية عبر CDP.

لقائمة الميزات كاملةً وHTTP API، راجع [README](../../README.md) الجذري.

> لا يزال قيد التطوير؛ قد يتغير الـAPI مستقبلًا.
