# shirabe

**Автоматизация браузера заново — управление headless-браузерами семейства Chromium через CDP с орт-подобным резолвером бэкенда без настройки.**

shirabe — это лёгкая Rust-нативная библиотека автоматизации браузера и
отладочный сервер. Она управляет любым браузером, говорящим на Chrome DevTools
Protocol — Google Chrome, Chromium, Microsoft Edge — через один движок CDP,
написанный вручную, и предоставляет всё это через небольшой HTTP-API. Это
браузерная основа, выделенная из упаковщика tairitsu и укреплённая для
самостоятельной работы.

Философия та же, что у [ort](https://crates.io/crates/ort) для ONNX Runtime:
**вам не нужно устанавливать браузер вручную.** Зафиксированная сборка Chrome
for Testing загружается в общий кэш (при сборке или при первом использовании),
прозрачно находится и управляется через CDP.

Полный список возможностей и HTTP-API см. в корневом [README](../../README.md).

> В разработке; API может измениться в будущем.
